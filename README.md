<h1 align="center" style="font-weight: bold;">Frontend</h1>

Este serviço tem por objetivo fornecer uma interface gráfica intuitiva e atrativa aos usuários para interagir com os serviços de Farmácia e Medicamento sem ter de operar diretamente com as APIs.

<h2>🛠️ Funcionalidades</h2>

- Interface gráfica intuitiva e simples
- Autenticação de usuário
- Gerenciamento de farmácias do usuário
- Gerenciamento de funcionários, medicamentos e lotes dentro de uma farmácia

<h2>💻 Tecnologias</h2>

- TypeScript
- Next.js
- Zod
- React Hook Form
- Axios

<h2>🚀 Instalação</h2>

<h3>Pré-requisitos</h3>

- Git
- Docker & Docker Compose

<h3>Clonar</h3>

```bash
git clone https://github.com/ProjetoEntregador/sophia-frontend.git
cd sophia-frontend
```

<h3>Configurar variáveis .env</h2>

Renomeie o arquivo `.env.example` para `.env`

<h3>Inicializando</h3>

```bash
docker-compose up -d
```

O projeto estará rodando em http://localhost:3004
